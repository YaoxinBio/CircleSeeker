# CircleSeeker 1.5.2 release preparation

Status: draft; final release and full dataset acceptance are pending.

This release fixes Cecc candidate identity and output integrity defects found
during review of v1.5.1. Active maintenance moves to YaoxinBio/CircleSeeker while
preserving original authors, licenses and history. See [provenance](../../PROVENANCE.md).

## Changes affecting results

- Repeat candidates from the same read retain their own sequence, length and RCA
  support. Missing candidate metadata cannot borrow another repeat's metadata.
- Classification and deduplication preserve segment direction and circular
  traversal order. Baseline structural merging keeps its 10 bp tolerance;
  experimental exact-sequence and 1% sequence thresholds were not adopted.
- Per-read RCA support is reconstructed from candidate support, separately from
  the aggregate for the molecule.
- Cecc BEDPE now includes all N junctions for N segments, including the closing
  junction; endpoints respect strand. Consumers assuming N-1 junctions must adapt.
- LAST identity is measured from alignment strings. Unavailable LAST MAPQ,
  low-MAPQ and associated confidence values remain missing rather than fabricated.
- Packaging fails on invalid confirmed Cecc sequence/length correspondence;
  final FASTA excludes inferred candidates removed from the final catalogue.

These corrections can change molecule counts, IDs, support totals and benchmark
metrics. A patch version does not imply identical scientific output. The older
endpoint numeric-comparison fix was already present in v1.5.1.

## Validation completed on the frozen repair code

- Linux/Python 3.12: 1,269 tests passed, one deselected; coverage 72.28%; mypy
  passed 59 source files. Build, installation and CLI checks passed.
- Replay of 55 flagged real-data candidates passed across 19 replay tasks.
- One complete raw-input benchmark passed all 16 pipeline steps: 4,817 catalogue
  rows matched 4,817 FASTA records, with no sequence-length or per-read support
  inconsistencies and 397 correctly closed directed junctions.
- That benchmark's overall F1 changed from 0.9524 to 0.9514. Cecc calls changed
  from 168 to 179, true positives stayed at 164, and false positives rose from 4
  to 15; Cecc F1 changed from 0.8913 to 0.8654. This is one scenario, not an
  estimate of average performance over the complete benchmark.

The additional batch contains 26 benchmarks and 33 real libraries. At the
2026-09-08 prepublication check, 18 of these 59 runs were independently validated,
7 were running and 34 had not started. This is a dated checkpoint, not a live
status report. Software CI for the release preparation is tracked on GitHub.
